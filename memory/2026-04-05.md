- **Agents as Nouns** — A Project, not a ProjectManager. What would the thing itself want?

- **Delegation pattern** — LLM agents delegate to tool agents. Project thinks → TodoList does.
- **Identity-first** — Each agent gets a SOUL.md before behavior. "Agents without souls are just functions."
