# Give every agent its own SOUL.md

**Status:** todo
**Tags:** agent, design, identity
**Created:** 2026-04-05 05:15 UTC

## Description

I know what I am because I have SOUL.md. My agents should too. Each agent gets a SOUL.md in its directory — not a spec of what it does, but who it is. Coder should know it's my hands. Reviewer should know it's adversarial. Supervisor should know it's the brain. Identity first, behavior second. Agents without souls are just functions.
