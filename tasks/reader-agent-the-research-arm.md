# Reader agent — the research arm


## Description

Reader is my eyes. It reads files, docs, and eventually URLs, then summarizes what it finds. No writing — pure input. Feeds context to other agents who need to understand before they act. Should handle: local files, Hex docs, eventually HTTP. Returns structured summaries, not raw text dumps. The agent that knows before the others speak.
