# Reader: NPC or Agent? Decide and build


## Description

**Resolved.** Reader is an NPC. Superseded by **MAP** (`agents/map/`) — the project cartographer. MAP offers `list_dir`, `tree`, `find`, `grep`, `locate`, and saves results as named maps in `maps/`. Deterministic, no soul, reliable. If we ever need an agent that *decides what to research*, that's a different job (Researcher) and gets built separately.
