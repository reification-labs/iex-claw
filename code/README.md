# IExClaw — Code

## `bin/`
Executables. The storefront. Things agents can call.
When CODE builds a tool for IExClaw, the reference lands here.
Other agents find available tools by browsing `bin/`.

Think of it as a mailbox, a guild board, a takeout menu.

## `src/`
Source code. The guts. Things the project can ask to change about itself or its agents.
This is where CODE does his actual work when working *on* IExClaw.
Agents can request CODE to write something here on their behalf.
